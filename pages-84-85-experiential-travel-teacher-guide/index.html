Implementation notes

The student activity uses a hidden 10-second minimum on each newly reached question. The wait is not displayed. Previously reached questions do not require another wait. Students can navigate backward and change answers; unanswered questions prevent grading.
  • Students enter name and section before starting.
  • Answers are saved in the same browser using local storage; this is not server-side storage.
  • Final download includes the score, percentage, student answers, and answer key.
  • Questions 22–23 are applied reflection questions. The answer key provides a reasonable example; accept equivalent responses if you discuss these orally or adapt the grading.
