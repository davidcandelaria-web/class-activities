Teacher Overview

Skill: Pronoun reference — students identify the noun or noun phrase replaced by a pronoun.

Student setup: Students first copy the Reading Skill box from the board. The student version presents one question at a time and uses a 10-second minimum active interval for each question.

Keep this teacher-guide link separate from the student link because the answers are visible.

Question 1Board example

Example 1 · Traveling

Use the reading-skill rule you copied. Read both sentences.

I love traveling. It makes me happy.

What does “It” replace?

Accepted answers: traveling · travelling
Answer: traveling
Question 2Board example

Example 2 · Planning a trip

What does “it” replace?

Answer: planning a trip

Question 19Skill check

Two pronouns

One pronoun refers to a person; one refers to a thing.

Elena found a map. She used it to find the museum.

Which pair is correct?

  1. She = Elena; it = a map ✓ CORRECT
  2. She = a map; it = Elena
  3. She = museum; it = find
Answer: She = Elena; it = a map
